# ApexMetrics Cloud Command Center (10X Edition)

An enterprise-grade cloud operations dashboard and infrastructure monitoring center built with Bootstrap 5.3, Chart.js 4.x, modern CSS3, and Vanilla JavaScript (ES6+).

## Live Demo
- **Live Site:** `https://deeppurohit7.github.io/admin-dashboard/`
- **Source Code:** `https://github.com/deeppurohit7/admin-dashboard`

## 10X Engineering Features
- **Live Real-Time Telemetry Heartbeat:** Auto-refreshing metrics for API throughput, server latency, and node load.
- **Interactive Multi-Dataset Chart:** Toggle between Revenue (INR), API Requests, and Latency curves across 7D, 30D, and 90D intervals.
- **Multi-Tab Architecture:** Seamless navigation across Overview Telemetry, Regional Cloud Nodes, and an automated Live Terminal Log Stream.
- **Advanced Table Engine:** Column sorting, live search across organizations/IDs, status pill filters, pagination, and client-side CSV spreadsheet export.
- **Infrastructure Management:** Interactive regional cluster health cards with custom deployment modals.
